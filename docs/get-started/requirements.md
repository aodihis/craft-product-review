# Requirements

### Craft CMS

Product Review requires Craft CMS 5.0.0 or greater.

### Craft Commerce

Product Review requires Craft Commerce 5.0.0 or greater.

### PHP

Product Review requires PHP 8.2 or greater.

{% hint style="info" %}
Craft Commerce must be installed before Product Review. Reviews are tied to Commerce products and orders, so installing without Commerce will fail.
{% endhint %}
